# 提交组员周报

1. 打开[组员周报](https://haodongwang01.github.io/group_meeting/weekly/)，选择对应周次，点击自己姓名所在行的「填写」。GitHub 会预填文件路径与[中文模板](TEMPLATE.md)。已提交的周报可在展开后点击「编辑周报」。
2. 替换第一行的一句话结论，在「本周进展」「问题或求助」「下周计划」下填写内容。本周进展至少写一项，其余两段可留空。正文支持段落、单层无序列表和 HTTPS 材料链接，例如 `[实验记录](https://example.org/results)`。
3. 提交更改。有仓库写权限可提交到 `main` 或创建拉取请求；其他组员可通过 GitHub 的分叉与拉取请求流程提交。合并到 `main` 后网站会自动发布。

每人每周一份文件，例如 `content/weekly/2026-11-23/林健.md`。日期取北京时间该周的周一，文件名使用周报页显示的姓名。从本地提交时，复制模板到对应路径后填写即可。空文件和原样模板显示为待更新。
